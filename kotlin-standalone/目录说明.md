| 路径 | 由什么产生 | 内容 / 用途 |

| `java_out.txt` | `javac` + `java ParityDump` | 12 行 `文件名\|类型\|结果`，Java 基准输出 |

## 四、生成关系

```
build.gradle.kts + src/*.kt
        │ gradlew -p kotlin-standalone build
        ▼
   build\classes → build\libs\*.jar
        │ installDist
        ▼
   build\install\switchquery-kotlin-preview\  （可直接运行）

samples/*.txt
   ├─ Kotlin `parity`  ─────────────▶ kotlin_out.txt
   └─ javac + ParityDump ──────────▶ java_out.txt
                                      （两者 diff / 哈希应完全一致）

tools\ParityDump.java + app\src\main\java\...\ResultRefiner.java
        │ javac -sourcepath app\src\main\java -d build-parity\java
        ▼
   build-parity\java\*.class   （Java 基准编译产物）
```

## 六、重建与清理说明

以下命令仅作参考，**执行前请自行确认**（删除前建议先备份或确认可重建）：

```powershell
cd f:\TRAE_Work\交换机信息查询APP
$env:JAVA_HOME = "C:\Program Files\Java\jdk-17.0.2"

# 重建编译与安装包
.\gradlew.bat -p kotlin-standalone build installDist

# 重新生成 Kotlin 对比输出
.\gradlew.bat -p kotlin-standalone run --args="parity samples kotlin_out.txt"

# 重新生成 Java 对比输出
javac -encoding UTF-8 -sourcepath app\src\main\java -d kotlin-standalone\build-parity\java `
  kotlin-standalone\tools\ParityDump.java
java -cp kotlin-standalone\build-parity\java ParityDump `
  kotlin-standalone\samples kotlin-standalone\java_out.txt

# 比对（应输出 True）
(Get-FileHash kotlin-standalone\java_out.txt).Hash -eq `
(Get-FileHash kotlin-standalone\kotlin_out.txt).Hash
```

- `.gradle`、`.kotlin`、`build`、`build-parity` 删除后，下次构建会自动重建；
- `java_out.txt`、`kotlin_out.txt` 删除后，按上面两条命令重跑即可；
- 源码、`samples`、`tools`、两份配置和两份文档**不要删**，它们是这个工程的资产。
